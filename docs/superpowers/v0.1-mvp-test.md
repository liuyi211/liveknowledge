# LiveKnowledge v0.1 MVP 测试步骤

## 环境准备

```bash
# 1. 确认数据库运行
docker compose ps
# 预期：lk-postgres (healthy), lk-neo4j (up)

# 2. 确认 Node 依赖已安装
cd backend && npm install
cd ../frontend && npm install
```

## 启动服务

**终端 1 — 后端**
```bash
cd backend
npm run dev
# 预期输出：Server running on http://localhost:3001
```

**终端 2 — 前端**
```bash
cd frontend
npm run dev
# 预期输出：http://localhost:3000
```

## 笔记系统 CRUD + Markdown 渲染（v0.1.1 新增）

> **前提**：跑 migration `npx drizzle-kit migrate`（产出 `0002_noisy_klaw.sql`，建 `folders` 表，给 `notes` 加 `folder_id`）。

### TC-N1：后端 — 文件夹 CRUD

```bash
# 列出文件夹（应为空数组）
curl http://localhost:3001/api/folders -b cookies.txt

# 新建根文件夹
curl -X POST http://localhost:3001/api/folders \
  -H "Content-Type: application/json" \
  -d '{"name":"日常"}' \
  -b cookies.txt
# 预期：返回 folder 对象，记下 id（设为 $F1）

# 新建子文件夹
curl -X POST http://localhost:3001/api/folders \
  -H "Content-Type: application/json" \
  -d "{\"name\":\"周记\",\"parentId\":\"$F1\"}" \
  -b cookies.txt

# 重命名
curl -X PATCH http://localhost:3001/api/folders/$F1 \
  -H "Content-Type: application/json" \
  -d '{"name":"日常笔记"}' \
  -b cookies.txt

# 防自循环（应 400）
curl -X PATCH http://localhost:3001/api/folders/$F1 \
  -H "Content-Type: application/json" \
  -d "{\"parentId\":\"$F1\"}" \
  -b cookies.txt

# 删除（级联）
curl -X DELETE http://localhost:3001/api/folders/$F1 -b cookies.txt
# 预期：子文件夹和子笔记应同步消失
```

### TC-N2：后端 — 笔记 folder/search

```bash
# 新建笔记到根
curl -X POST http://localhost:3001/api/notes \
  -H "Content-Type: application/json" \
  -d '{"title":"行列式","content":"# 行列式\n它是一个标量..."}' \
  -b cookies.txt
# 记下 id（设为 $N1）

# 移动到文件夹
curl -X PATCH http://localhost:3001/api/notes/$N1 \
  -H "Content-Type: application/json" \
  -d "{\"folderId\":\"$F1\"}" \
  -b cookies.txt

# 按文件夹列出
curl "http://localhost:3001/api/notes?folderId=$F1" -b cookies.txt

# 根目录笔记（folderId 为 null）
curl "http://localhost:3001/api/notes?folderId=root" -b cookies.txt

# 搜索（标题/正文 ILIKE）
curl "http://localhost:3001/api/notes?q=%E8%A1%8C%E5%88%97%E5%BC%8F" -b cookies.txt
# 预期：返回标题或正文含「行列式」的笔记
```

### TC-N4：前端 — Markdown 渲染

在编辑器写入下面内容（任意一条已选中的笔记）：

````markdown

**粗体**、*斜体*、~~删除线~~、`inline code`

- 列表 1
- 列表 2
  - 嵌套

- [ ] 任务 1
- [x] 任务 2（已完成）

> 引用块

行内公式 $E=mc^2$，行间公式：

$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$

```js
function hello() {
  return "world";
}
```

| 列 1 | 列 2 |
|------|------|
````

### TC-N11：拖拽移动（v0.1.2 新增）

1. **笔记 → 文件夹**：拖任意笔记，hover 文件夹 → 文件夹高亮（蓝底蓝边框）；松开 → 笔记移入，文件夹自动展开
2. **文件夹 → 文件夹**：拖文件夹 A，hover 文件夹 B → B 高亮；松开 → A 成为 B 的子文件夹
3. **拖到根**：拖笔记/文件夹松开在树的空白区 → 移到根目录（顶级）
4. **防自循环**：拖文件夹 A，hover A 自身或 A 的子文件夹 → 不高亮，目标半透明（opacity-50），松开无操作
5. **失败回滚**：若后端拒绝（如绕过前端检查直接 fetch），弹 alert 提示原因

### TC-N12：删除确认小弹窗（v0.1.3 新增）

替换 `window.confirm()` 为自定义 Radix Dialog 小弹窗。

1. **删除笔记**：右键笔记 → **删除** → 中央弹窗显示「确定删除笔记「xxx」？此操作不可撤销。」，点 **删除** 红色按钮 → 笔记消失
2. **删除空文件夹**：右键文件夹 → **删除文件夹** → 弹窗显示「确定删除空文件夹「xxx」？」
3. **删除非空文件夹**：弹窗显示「将级联删除 N 个子文件夹和 M 条笔记。」（数字红色加粗）
4. **键盘**：Enter 确认删除，Esc 取消
5. **失败提示**：若后端 5xx，alert 错误，弹窗保留可重试
6. **busy 防双击**：点击删除后按钮变「删除中…」并禁用，避免重复请求

### TC-N13：行内新建文件夹（v0.1.3 新增）

替换 `window.prompt()` 为行内输入（同新建笔记体验）。

1. **根目录新建**：点工具栏 **新建文件夹** 图标 → 树中立刻出现「新建文件夹」行，rename input 自动 focus 且文字全选
2. 输入名字 → 回车 → 文件夹改名落定
3. Esc / blur 但未改名 → 文件夹保留默认名「新建文件夹」（与新建笔记保留「无标题」一致）
4. **子文件夹**：右键已有文件夹 → **新建子文件夹** → 同上行为，父文件夹自动展开

| 问题 | 原因 | 解决 |
|------|------|------|
| 聊天无响应 | 未配置 AI Provider | 先执行 TC-04 |
| RAG 检索不到笔记 | embedding 尚未生成 | 创建笔记后等待几秒再试 |
| 前端无法登录 | CORS 或后端未启动 | 确认后端在 3001 运行，且 CORS origin 为 3000 |
| 端口占用 | 上次进程未退出 | `npx kill-port 3001` 或 `npx kill-port 3000` |
| 笔记树不显示 | folders 表不存在 | 跑 `cd backend && npx drizzle-kit migrate` |
| Markdown 公式不渲染 | KaTeX CSS 未加载 | 确认 `frontend/src/app/globals.css` 含 `@import 'katex/dist/katex.min.css'` |
| 右键菜单不出现 | Radix 未装 | `cd frontend && npm i @radix-ui/react-context-menu @radix-ui/react-dialog` |
