这份计划用于跟踪项目从当前 MVP 雏形走向完整实现的进度。每完成或完善一项，就把 `[ ]` 改为 `[x]`。

## 0. 工程可运行

- [x] 搭好前后端分离结构：`frontend` / `backend` 独立存在，技术栈匹配规划。
- [x] 配置 PostgreSQL + pgvector + Neo4j：`docker-compose.yml` 可启动数据库服务。
- [x] 修复后端 TypeScript build：`backend npm run build` 通过。
- [x] 修复前端 TypeScript build：`frontend npm run build` 通过。
- [x] 修复全项目中文乱码：UI 文案、错误信息、LLM prompt 全部恢复正常中文。
- [x] 清理废弃/重复实现：移除或归档旧 `rag.ts` 等不再使用的 MVP fallback。

## 1. 用户与设置

- [x] 用户注册/登录/session：能注册、登录、退出、校验当前用户。
- [x] AI Provider 配置：支持保存、测试、启用 chat/embedding Provider。
- [x] Provider 密钥加密：API key 加密存储，不明文暴露。
- [x] 模型能力管理：明确 vision、streaming、reasoning、context window 等能力。
- [x] 设置页完善：Provider、检索参数、模型选择体验完整可用。

## 2. AI 对话

- [x] 会话列表/新建/删除：前端可完整管理会话。
- [x] SSE 流式回复：用户能看到实时生成内容。
- [x] thinking/reasoning 展示：DeepSeek/Codex 类模型思考内容独立显示。
- [x] 停止生成：前端可 abort 当前生成。
- [x] 编辑重发/重新生成：行为稳定，历史版本关系正确。
- [x] Persona 会话级切换：切换导师时携带上下文摘要。
- [x] 多模型消息级切换：单轮可指定模型，并处理上下文长度差异。
- [x] 附件体验完善：图片、PDF、文档、URL 都能稳定解析并进入上下文。

## 3. 笔记系统

- [x] 笔记 CRUD：创建、编辑、删除、搜索可用。
- [x] 文件夹树：文件夹、移动、重命名、删除可用。
- [x] Markdown/LaTeX 预览：Markdown、代码块、KaTeX 正常渲染。
- [x] 自动保存/冲突处理：编辑不会误丢内容，多端/快速操作稳定。
- [x] 标签体系完善：标签编辑、筛选、统计可用。
- [x] 笔记来源追踪：从对话/导入/提炼生成的笔记能追溯来源。

## 4. 索引与 RAG

- [x] 笔记 chunking：Markdown/文本结构感知切分。
- [x] embedding 入库：笔记可生成向量并写入 pgvector。
- [x] 修复全文检索 schema：`search_vector` 字段、索引、迁移与代码一致。
- [x] 中文全文检索：pg_jieba 或替代方案可用。
- [x] Query Rewrite：输出结构化 rewritten query、keywords、sub_queries、intent。
- [x] HyDE 可选策略：模糊问题可用假设答案辅助检索。
- [x] RRF 融合：向量、全文、图谱结果稳定融合。
- [x] rerank 完善：轻量模型重排结果可靠，成本可控。
- [x] 上下文预算管理：能按 token 预算去重、截断、注入 prompt。

## 5. 知识提炼

- [x] note 提炼 job：从笔记创建提炼任务并查看进度。
- [x] conversation 提炼：从完整会话生成笔记、卡片、概念。
- [ ] document/import 提炼：从上传文档和导入内容创建提炼任务。
- [ ] 预处理 + 日志：每个步骤有可追踪日志和失败原因。
- [ ] 用户预览采纳：可选择采纳笔记、卡片、概念、关系。
- [x] 保存 cards：`adopt` 真正写入 cards 表。
- [ ] 防重复/版本追踪：同一来源重复提炼可识别和比较。

## 6. 复习系统

- [ ] cards 完整数据模型：difficulty、half_life、next_review_at、review logs 完整。
- [ ] SSP-MMC 调度：Again/Hard/Good/Easy 后计算下次复习时间。
- [ ] 复习队列 API：查询今日到期卡片并排序。
- [ ] 复习前端：翻卡、自评、下一张、进度反馈完整。
- [ ] 复习历史：每次评分、响应时间、参数变化可追踪。
- [ ] 图谱联动：复习卡片时展示关联知识点上下文。

## 7. 知识图谱

- [ ] Neo4j 基础写入：Note、Concept、Relation 能写入图数据库。
- [ ] 关系抽取稳定化：关系类型受控，非法 Cypher 类型不会污染图。
- [ ] 图查询 API：支持按节点、领域、连接强度查询。
- [ ] D3 图谱前端：可缩放、拖拽、筛选、点击查看详情。
- [ ] 笔记/卡片跳转：图节点能跳转到对应笔记或卡片。
- [ ] 社区发现/摘要：社区聚类和主题摘要稳定可用。

- [ ] 数据采集：对话、复习、浏览、搜索行为可记录。

## 推荐执行顺序

1. 先修工程底座：build、乱码、schema 不一致。
2. 再把“聊天 + 笔记 + RAG”主线做稳。
3. 然后完成“提炼 -> 卡片 -> 复习”的学习闭环。
4. 接着做知识图谱可视化和认知画像。
5. 最后补仪表盘、导入、测试和文档。
